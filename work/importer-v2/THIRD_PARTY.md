# Third-party components and references

- Go standard library/runtime, BSD license.
- gorilla/websocket v1.5.3, BSD 2-Clause license. Source and license are in `源码/vendor/github.com/gorilla/websocket/`.
- Public research references for Steam CEF/collectionStore: `sjmatta/steam-mcp` (MIT) and `nobodys-tools/DeckDex`. This tool independently implements its Windows/macOS startup, preview planning, journal recovery, and Go CDP transport; these projects are not installed.

Steam is a Valve product. This is an independent third-party utility, not official Valve software.

The game list, classification records, and backups may contain private library information. Keep them secure; the program reads and writes these files locally.
